# IRONFORGE ATHLETICS

Premium fitness, strength and performance platform.

## Stack
Next.js · TypeScript · Tailwind CSS · Framer Motion · Supabase · Paystack/Flutterwave

## Production configuration
Copy `.env.example` to your deployment environment and configure the Supabase project credentials plus payment-provider secrets. Never expose secret payment keys or Supabase secret/service-role keys in client code.
